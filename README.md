### 🏆 Flagship Project — ClassTrack

**AI-powered university attendance & performance system**, built as my graduation project with an 8-person team — submitted to **AYAIR 2026** (Presidential African Youth in AI and Robotics).

- 🔐 10-second HMAC-signed QR tokens — kills proxy attendance
- 🧠 On-device face verification: YOLOv8 + FaceNet (512-D embeddings) via a Flask API — **94.3% TAR, <0.1% FAR**
- 📡 Offline-first with SQLite → Supabase (PostgreSQL + RLS) sync
- 📈 Linear regression grade predictor (R² 0.847) flags at-risk students **5 weeks earlier** than midterm-based methods
- ✅ 47/47 test cases passed, 83.2% coverage, validated in a live pilot at MTI University

*Four role-based apps: Student, Faculty Dashboard, T.A., Admin — full CRUD, analytics, PDF/Excel export.*

### ⚡ Also Building — Real-Time Voice & Video Calling

A peer-to-peer voice & video calling system on **WebRTC + Supabase Realtime**, with live ICE candidate exchange and full call-state management (Ringing → Connecting → Connected → Ended). Handles anonymous auth, camera switching, mic mute, and speaker toggle — and solves ICE candidate race conditions via candidate buffering when candidates arrive before the call record exists in the database.
